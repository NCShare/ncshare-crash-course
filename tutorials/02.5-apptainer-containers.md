# Apptainer containers

## Inspect and run the course container

An Apptainer **SIF image** is a read-only file containing an application and its user-space software environment. The [NCShare software guide](https://userguide.ncshare.org/guides/slurm/software/) explains why containers are the normal route for packaged scientific software on NCShare.

First, request an interactive Slurm job on a compute node,
```bash
srun -p workshop --time=00:10:00 --cpus-per-task=2 --mem=1G --pty bash -i
```

Then run the following on it,
```bash
export COURSE_IMAGE="/opt/apps/containers/users/ncshare-science-course.sif"
apptainer --version
apptainer inspect "$COURSE_IMAGE"
apptainer exec "$COURSE_IMAGE" python --version
apptainer exec "$COURSE_IMAGE" mpirun --version
```

You can also drop down into the container through a `shell` with,

```bash
apptainer shell "$COURSE_IMAGE"
exit
```

- `export NAME=value` creates a shell variable and makes it available to programs started from the shell. We store the long image path once in `COURSE_IMAGE` so later commands are easier to read.
- `apptainer --version` checks that Apptainer is installed on the host.
- `apptainer inspect IMAGE` prints labels and metadata stored in the image.
- `apptainer exec IMAGE COMMAND` runs one command using software from the image. Here it reports the packaged Python and MPI versions.
- `exit` leaves the shell and another `exit` leaves the compute shell and returns to the login node. The allocation also ends when its time limit expires.

## Slurm batch job with container

Create the following `submit.sh`,
```bash
#!/bin/bash
#SBATCH -J apptainer_test      # Job name
#SBATCH -p workshop            # Partition name
#SBATCH --cpus-per-task=2      #CPUs-per-task
#SBATCH --mem=1G               # Memory per node

export COURSE_IMAGE="/opt/apps/containers/users/ncshare-science-course.sif"
apptainer exec "$COURSE_IMAGE" python --version > python-version.txt
apptainer exec "$COURSE_IMAGE" mpirun --version > mpirun-version.txt
```

Submit job with, 
```shell
sbatch submit.sh
```
